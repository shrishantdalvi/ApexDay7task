# Day 07 – Business Data Analysis Using Python & Pandas

## Project Overview
This project focuses on analyzing retail sales data using Python and its data analysis libraries. The objective is to clean the dataset, calculate important business KPIs, identify sales trends, and generate meaningful business insights.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- VS Code

## Dataset Information
The dataset contains retail transaction details, including:
- Order and Shipping Dates
- Customer Information
- Product Categories and Sub-Categories
- Sales, Quantity, Discount and Profit
- Region, State and City

## Data Cleaning & Quality
- Checked missing values and duplicate records.
- Found 0 missing values and 0 duplicate records.
- Checked unique categorical values:
  - 531 Cities
  - 49 States
  - 1 Country
  - 3 Segments
  - 3 Categories
  - 4 Regions
  - 17 Sub-Categories
- Corrected inconsistent Order Date and Ship Date formats and converted them into datetime format.

## Analysis Performed
1. Dataset exploration and statistical summary.
2. Business KPI calculations.
3. Best-selling product and highest revenue category analysis.
4. Top 10 customers by sales.
5. Top 5 cities by revenue.
6. Data filtering and conditional analysis.
7. Grouping and aggregation by region, category, month, customer and product.

## Data Visualizations
Created three visualizations using Matplotlib:
- Monthly Sales Trend – Line Chart
- Sales by Category – Bar Chart
- Top 10 Customers by Sales – Horizontal Bar Chart

## Key Business Insights
- **Highest Revenue Region:** West
- **Most Profitable Category:** Technology
- **Highest Sales Month:** November 2017
- **Highest Revenue Customer:** Sean Miller

### Business Recommendations
- Improve sales strategies in underperforming regions.
- Focus on profitable Technology products.
- Retain high-value customers through loyalty programs.
- Analyze peak-month sales trends to plan future promotions.

This project demonstrates how Python, Pandas, NumPy and Matplotlib can be used to clean retail data, perform business analysis, visualize trends and support data-driven decision-making.
